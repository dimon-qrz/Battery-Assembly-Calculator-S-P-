 # 🔋 Battery S/P Calculator

> Легкий, швидкий та адаптивний веб-інструмент для радіоаматорів, майстрів та інженерів, призначений для розрахунку параметрів акумуляторних батарей при послідовному (S) та паралельному (P) з'єднанні елементів.

🔗 **Спробувати онлайн:** [Battery-Assembly-Calculator-S-P-](https://dimon-qrz.github.io/Battery-Assembly-Calculator-S-P-/)

## 📌 Можливості

### 1. Двостороння синхронізація розрахунків
* **Розрахунок за кількістю банок:** Вкажіть кількість елементів послідовно (S) та паралельно (P) — калькулятор миттєво покаже номінальну напругу збірки та загальну кількість необхідних акумуляторів.
* **Підбір за напругою:** Введіть бажану робочу напругу (наприклад, 12V, 24V, 48V), і інструмент автоматично розрахує необхідну кількість послідовно з'єднаних банок.

### 2. Підтримка популярних хімічних типів
Калькулятор має передустановки для автоматичного розрахунку залежно від хімії:
* **Li-ion:** номінальна напруга 3.6V.
* **LiFePO4:** номінальна напруга 3.2V.
* **Lead-Acid (Свинець):** номінальна напруга 2.0V.

### 3. Інтерактивна візуалізація
* **Динамічна матриця:** Графічно відображає структуру вашої майбутньої батареї.
* **Безпека:** Допомагає уникнути помилок при монтажі та комутації шин.
